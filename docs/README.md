## Структура репозитория

Репозиторий организован в соответствии с требованиями:

- `README.md` — общая информация о практике и проекте
- `docs/` — документация в Markdown (данный файл)
- `reports/` — итоговый отчёт в форматах DOCX и PDF
- `site/` — статический сайт проекта (HTML, изображения)
- `src/` — исходный код Telegram-бота
