# Описание проекта «SPARQ»

## Название проекта

SPARQ — AI-платформа для студентов и преподавателей Московского Политехнического университета

## Цель проекта

Повысить эффективность учебного процесса и командной работы в университете, предоставив единую цифровую среду: автоматическая расшифровка лекций, управление задачами и командная коммуникация — в одном продукте, разработанном силами студентов Мосполитеха.

## Задачи проекта

- Разработать ML-пайплайн для автоматической расшифровки видеолекций (speech-to-text)
- Создать REST API на FastAPI с авторизацией, интеграцией PostgreSQL и S3-хранилища
- Реализовать фронтенд на React + TypeScript с интеграцией всех API
- Спроектировать и запустить модуль Task Manager (Kanban-доски)
- Спроектировать и запустить модуль Messenger (командный чат)
- Обеспечить CI/CD и деплой платформы через Docker + Coolify
- Разработать дизайн-систему и UI-kit в Figma
- Подготовить документацию: стек технологий, глоссарий, Q&A, паспорт проекта

## Продукты проекта

- **ML-сервис расшифровки** — загрузка видео → аудиоэкстракция → Whisper/Sber STT → транскрипт с тегами и структурой
- **Task Manager** — Kanban-доски с колонками, карточками задач, drag & drop, assignee, дедлайнами, тегами и командным доступом
- **Messenger** — Slack-подобный мессенджер с каналами, личными сообщениями и поиском
- **Статический сайт** — сайт проекта с описанием, командой, журналом и ресурсами
- **Документация** — полный пакет технической и продуктовой документации
