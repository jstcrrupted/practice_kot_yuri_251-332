О проекте

Что такое
SPARQ?

От расшифровки лекций до полноценной рабочей платформы с Task Manager и Messenger

SPARQ — студенческий IT-продукт, разработанный в рамках проектной деятельности Московского Политехнического университета. Изначально проект стартовал как сервис расшифровки видеолекций с помощью искусственного интеллекта: студенты и преподаватели могли автоматически получать текст, конспекты и ключевые тезисы из учебных видео.

В процессе работы платформа выросла в полноценную рабочую среду: появился модуль управления задачами с kanban-досками и мессенджер с каналами и личными сообщениями — всё в фирменном стиле Мосполитеха.

Проект полностью разработан командой студентов. Фронтенд — React + TypeScript, бэкенд — FastAPI + PostgreSQL + S3, ML-пайплайн строится на speech-to-text моделях. Задеплоено через Coolify + Docker с автоматическим CI/CD.

Как развивался

Ключевые вехи и итерации разработки SPARQ с октября 2025 по май 2026

OCT 2025

Старт: MVP расшифровки видео

Команда собрана — больше 30 студентов из разных групп. Запущен первый ML-пайплайн для расшифровки видеолекций: API принимает видео, извлекает аудио, прогоняет через Whisper STT и отдаёт текст. Параллельно разработан UI авторизации на React, спроектирована БД в PostgreSQL, созданы базовые REST-эндпоинты. Развёрнута база данных на сервере, начато оформление Figma-дизайна всех экранов.

ML Pipeline v1 FastAPI React UI Завершено
DEC 2025

Интеграция: S3, PostgreSQL, CI/CD

Бэкенд полностью переведён на реальную БД и S3-хранилище. Подключена авторизация через JWT с хранением сессий в PostgreSQL. ML-сервис переведён на асинхронные задачи — пользователь видит статус обработки в реальном времени. Фронтенд интегрирован с API: загрузка видео с прогресс-баром, страница результатов, экспорт. Настроен Coolify для автодеплоя. Проведена защита первого семестра.

PostgreSQL S3 Storage Docker CI/CD Coolify Защита прошла
FEB APR 2026

Task Manager: полный Kanban

Реализован модуль Task Manager — полноценный аналог WEEEK в стиле Мосполитеха. На бэкенде: схема данных досок, колонок и карточек, CRUD API, reorder с пересчётом позиций, теги, участники. На фронтенде: kanban-доска с drag&drop внутри и между колонками, карточки с assignee и дедлайном, быстрое создание задач, фильтрация. Собран полный UI-kit, проведено e2e-тестирование.

Kanban Board Drag & Drop REST API Figma UI-kit В продакшене
APR MAY 2026

Messenger и финальная платформа

Запущен Messenger с каналами, личными сообщениями и инфраструктурой для real-time. Дизайн полностью перепроектирован: новые макеты, редизайн Task Manager. Проведена инвентаризация API, закрыты все пробелы для ТОП-10 страниц. Настроены инструкции по логам, шаблоны env. Проект подготовлен к итоговой защите.
